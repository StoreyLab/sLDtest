# sLDtest
An R package that implements a hypothesis testing method of structural linkage disequilibrium (sLD).  
  
This R package is under development. For now, please visit the repository that reproduces the results in the paper, "A test for linkage disequilibrium in structured populations" by Alvin J. Zhang and John D. Storey:  
  
https://github.com/StoreyLab/sLD-manuscript-analysis
